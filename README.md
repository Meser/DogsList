# iOS Technical Test

This application built with **Swift (VIPER)** allows you to download, view, and manage a video game catalog from the public URL https://jsonblob.com/api/1151549092634943488, using **UserDefaults** for local storage.

## 📱 Features

- Initial download from: `(https://jsonblob.com/api/1151549092634943488)`
- Display a list of dogs
- Pull to refresh
- Dogs detail view
- Local persistence

## 🛠 Requirements

- Xcode 15+
- Swift 5.9+
- iOS 16+
